# Prosperity rules

Price: **$8–$12 / user / month**. Same band as Linear Plus. We do not undercut on taste. We do not out-feature ClickUp.

## What we sell

1. Agent assignee with a cost cap.
2. One portfolio board across every Mangu repo, tagged `cash-engine` or `lab`.

That is the whole wedge.

## What Linear owns

Taste. Motion design. Keyboard religion. Cycle aesthetics. We steal the speed discipline and refuse to compete on "feels expensive."

## Kill criteria

Kill or freeze feature work if any of these fire:

- We add a 12th module (docs, chat, time, goals, workload, whiteboards, forms, proofing, CRM, OKRs, calendar, Gantt) before GitHub one-way sync writes a real `issue_links` row.
- Time-to-first-issue on a new laptop exceeds 60 seconds of setup after `npm i && npm run dev`.
- A cash-engine product cannot be distinguished from a lab on the home board.
- Agent assignment is implemented as a label named "alice" instead of `assignee_kind`.

## Cost posture

- Static-first. Cheap Vercel function budget.
- Supabase free tier is enough for the operator set (<10 humans).
- Agent spend is an issue field, not a hidden vendor invoice. Surface it.

## Time-to-value

A Mangu operator should:

1. Open the board.
2. See every product tagged.
3. File an issue to Alice with a $2 cap.
4. Sync GitHub issues for `my_publishing`.

All four in the first sitting. If not, the product is theatre.
