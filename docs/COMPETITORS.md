# Competitor matrix

Scored August 2026. Scores 1–5. Higher is better for *our* job: create speed, agent field, portfolio multi-repo, price, time-to-value.

Linear GraphQL create: `issueCreate({ title, teamId, description })` at `https://api.linear.app/graphql`.
GitHub: REST issues or GraphQL `createIssue`. Projects v2 needs a second mutation `addProjectV2ItemById`.

## Height and Plane vs Linear

- Linear: fastest create (~8s keyboard path in timed tests), owns taste, GitHub linking is best-in-class. Agent exists on Business as Linear Agent / triage — not a cost-capped swarm field. Portfolio is workspace teams, not cash-vs-lab across dozens of repos.
- Height: AI is the product (auto-assign, smart lists). Slower create (~12s). Cheaper mid-tier. No engine tag.
- Plane: open-source Linear shape. Wins self-host and TCO (~$6 cloud / free SH). Loses raw UI speed and agent-as-assignee.
